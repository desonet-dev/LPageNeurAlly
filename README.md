# LPageNeurAlly

Página web no formato landing page sobre o projeto de TCC NeurAlly, apresentada para o curso técnico de Desenvolvimento de Sistemas na Etec de Taboão da Serra no ano de 2026.

## Sobre o projeto

O NeurAlly é um aplicativo mobile que visa democratizar o acesso à tratamentos psicológicos e profissionais de saúde mental, facilitando-os por meio de ferramentas que possibilitam o agendamento de consultas online ou presenciais, realizar videochamadas, possibilitar a conversa por mensagens e disponibilizar um diário emocional e jogos relaxantes para acompanhamento diário. 

* Videochamada para realização das consultas online por meio do aplicativo
* Troca de mensagens por meio do aplicativo
* Registros para o diário emocional
* Questionário de triagem
* Sistema de pagamento das consultas
